# 2026-07-28 工作日志

## Gradio Web UI 开发（web_ui.py）

### 背景
用户要求为电商客服 Agent 做一个界面 UI。确认方案：Gradio Web UI + 完整复刻 CLI 功能。

### 实现
- 新建 `web_ui.py` 作为 Web 入口，复用 CLI 全部业务逻辑，零侵入改造
- 复用的纯函数：`run_agent()` / `login_user()` / `register_user()` / `list_sessions()` / `clear_memory()` / `clear_all_memory()` / `save_memory()` / `get_recent_chat_records()` / `normalize_session_name()` / `_next_auto_session()`
- UI 结构：登录页（角色单选+用户名+密码+登录/注册）+ 主界面（左侧聊天区 Chatbot+输入框，右侧会话管理栏：会话列表/新建/切换/清空/重新登录）+ 顶部状态栏
- 登录态用 `gr.State(dict)` 维护，每个浏览器会话独立
- 保留 CLI 入口 `main_agent.py` 不变，双入口模式

### Gradio 6.20.0 适配要点
- `theme`/`css` 参数从 `gr.Blocks()` 构造函数移到了 `demo.launch()` 方法
- `gr.Chatbot` 移除了 `type` 参数，6.x 统一使用 messages 格式 `{"role":..,"content":..}`
- 启动命令：`python web_ui.py`，访问 http://localhost:7860

### 启动验证
- 导入测试通过，模型加载正常（bge-base-zh-v1.5 + fallback）
- 服务启动成功，端口 7860 返回 HTTP 200
