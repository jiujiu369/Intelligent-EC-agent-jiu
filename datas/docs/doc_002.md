# doc_id：002 | 类目：买家售前商品咨询 | 适用商品：服饰

## 尺码选择指导

服装尺码选择需根据买家身高体重数据推荐。标准S码适合身高155-160cm、体重40-45kg，M码适合160-165cm、体重45-50kg，L码适合165-170cm、体重50-55kg，XL码适合170-175cm、体重55-65kg。询问买家平时穿着习惯，喜欢宽松还是修身效果，根据偏好调整尺码推荐。不同品牌版型略有差异，建议买家参考具体商品详情页的尺寸对照表。如买家身材特殊，可推荐选择大一号并咨询是否可以改裤脚或袖长。提醒买家收到商品后保留吊牌和包装，方便7天无理由退换。

## 面料护理说明

服装面料护理直接影响穿着寿命。棉麻类服装建议手洗或轻柔机洗，水温不超过30℃，避免暴晒导致褪色。真丝和羊毛类需要干洗，不能用洗衣机搅洗，避免缩水和变形。化纤类可正常机洗，但要注意拉上拉链和扣上扣子，避免刮伤面料。深色衣物首次洗涤时建议加入食盐固色，防止褪色。存储时建议悬挂存放，避免长期折叠产生永久折痕。提醒买家洗涤前查看服装内侧洗标，按照标注的护理方式清洗。
