# doc_id：282 | 类目：买家售前咨询 | 适用品类：3C数码
## 规则内容
买家咨询显示器基础参数、使用调节问题统一应答规范。消费者咨询显示器刷新率、面板类型、自带USB接口使用方式时，客服需精准告知硬件参数并给出实操步骤。常规家用IPS显示器出厂标准刷新率为60Hz，电竞款可达144Hz、165Hz；机身自带USB拓展口需配套附赠USB上行线连接电脑主机才能供电传输外设，仅插显示器供电无法使用拓展功能。若买家反馈屏幕发黄，引导进入显示器OSD菜单调节色温，切换冷色调模式即可改善；部分机型支持预设标准、暖、冷三档色温，无多档位则手动降低黄、红数值。商品页面标注参数与实物一致，显示器标配电源线、视频线、USB上行线，无配件加价情况。整机一年全国联保，人为屏幕碎裂不在免费保修范围，人为损坏维修需收取屏幕物料费与手工检测费，检测费用以售后站点报价为准。签收前请检查外包装完好，拆封后非人为屏幕故障可退换，人为损坏仅支持付费维修。
