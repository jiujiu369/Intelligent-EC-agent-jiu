# doc_id：384 | 类目：买家售前咨询 | 适用品类：卫浴洁具
## 规则内容
马桶、盖板售前参数与配套咨询统一应答规范。马桶标准坑距分为300mm、400mm两种，下单前需告知用户测量墙面到排污管中心距离，选错型号可换货，但往返物流由买家承担。全套产品标配法兰密封圈、固定螺丝、静音缓降盖板，无额外付费配件；盖板松动仅需自行调节底部紧固螺母，属于简易调试问题，不属于质量故障。陶瓷釉面人为磕碰开裂不在免费质保范围，原厂釉面瑕疵、冲水故障整机一年免费补发配件。商品不附赠上门安装服务，如需师傅上门可自行预约平台安装师傅，单独收取安装服务费。盖板配件单独售卖，损坏可只补发盖板，无需整套更换，同时告知用户日常保养避免强酸清洁剂腐蚀釉面。
